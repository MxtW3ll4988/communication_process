### Nota sobre el código fuente

El código presentado corresponde a la versión funcional final del sistema de comunicación mediante luz visible (VLC). No obstante, podrá estar sujeto a modificaciones y optimizaciones previas a la entrega definitiva, con el propósito de mejorar su eficiencia, estabilidad y rendimiento en el enlace de comunicación.

Asimismo, el código se encuentra documentado de manera integral para facilitar su comprensión, mantenimiento y seguimiento de la lógica de funcionamiento tanto del emisor como del receptor.
